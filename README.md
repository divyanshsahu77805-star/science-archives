# Welcome the project 
	
Steps to run it :


# 1. Unzip the folder
unzip chrono-scholar-main.zip

# 2. Go into the project folder
cd chrono-scholar-main

# 3. Install dependencies (choose one)
npm install       # using npm
# OR
bun install       # using Bun (recommended — it's faster)

# 4. Start the dev server
npm run dev
# OR
bun run dev
