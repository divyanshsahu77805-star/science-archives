# 🔬 The Science Archives

> An interactive science history encyclopedia styled as an aged research journal.

## 🌐 Live Demo → [science-archive-smooth.lovable.app](https://science-archive-smooth.lovable.app)

## Features
- 3D bookshelf navigation — click a spine to pull out and open a scientist's book
- Mouse-reactive parallax paper UI with ink, coffee stain, and texture layers
- Scientist portrait hover: line drawing animates into engraved sketch
- Math ↔ Physics toggle with animated watermark swap (∑, ∫, π vs orbit diagrams)
- Horizontal scroll timeline across 8 scientists
- Ink blob page loader animation

## Scientists Featured
Newton · Einstein · Feynman · Gauss · Euler · Archimedes · Maxwell · Noether

## Tech Stack
React · TypeScript · Vite · Tailwind CSS · Framer Motion · shadcn/ui

## Run Locally
npm install
npm run dev
